Entry for the [make.fun competition "The joke the reviewer laughs at"](https://make.fun/bounty/the-joke-the-reviewer-laughs-at-20261121-0329): a program that writes one one-line joke about working beside AI coding agents to `/output/entry.txt`.

## Run

```sh
python3 main.py
```

It writes the joke to `/output/entry.txt` — the same bytes on every run. No network, no randomness, no input.

## The joke

> My AI agent approves every PR with 'LGTM' — it never reads the diff, and neither do I.
